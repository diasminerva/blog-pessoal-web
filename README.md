# 🌐 Blog Pessoal - Front-end (React + TypeScript)

Interface web moderna desenvolvida como Single Page Application (SPA) para gerenciamento de postagens e temas, consumindo API RESTful com autenticação JWT.

---

## 🛠️ Tecnologias Utilizadas

* **React 19 & TypeScript:** Construção de interfaces componentizadas e com tipagem estática.
* **Vite:** Ferramenta de build e bundling de alta performance.
* **Tailwind CSS:** Estilização utilitária e layout responsivo.
* **React Router DOM:** Roteamento e navegação client-side.
* **Axios:** Consumo de endpoints RESTful com envio de tokens no cabeçalho.
* **Context API:** Gerenciamento global de autenticação e sessão do usuário.
* **React Toastify:** Notificações e alertas visuais de ações do sistema.

---

## ⚙️ Funcionalidades

* 🔐 **Autenticação & Segurança:** Cadastro de novos usuários e fluxo de login seguro com token JWT.
* 📝 **CRUD de Postagens:** Criação, listagem, edição e exclusão de publicações.
* 🏷️ **CRUD de Temas:** Gerenciamento de categorias para organização do conteúdo.
* 👤 **Área de Perfil:** Exibição dos dados e foto da usuária autenticada.

---

```bash
